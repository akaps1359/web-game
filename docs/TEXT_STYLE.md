# 게임 문장 가이드

화면에 나오는 모든 한국어 문장의 기준이다. 새 콘텐츠와 UI도 이 가이드를 따른다.
목표는 "기계가 번역하거나 AI가 풀어 쓴 설명문"이 아니라 "사람이 만든 게임의 문장"으로 읽히는 것이다.

## 1. 말투는 넷

| 어디 | 말투 | 예 |
|---|---|---|
| **확인 창**: 되돌릴 수 없는 일을 묻는 창(제목과 본문) | 해요체. 화면에서 해요체를 쓰는 곳은 여기뿐이다 | "이번 여정을 포기할까요?", "지금까지 얻은 것은 모두 사라져요." |
| **그 밖의 시스템 UI**: 버튼, 안내, 알림(토스트), 빈 칸 안내, 도움말·용어집, 의도 설명 | 해라체나 짧은 명사형. 버튼은 짧은 동사나 명사 | "저장 완료", "골드 부족", "누르면 설명. 한 번 더 누르면 사용", 버튼 "포기", "흡수" |
| **세계 서술**: 이벤트 본문·결과, 적·정수·유물·장비의 맛글, 속삭임, 탐험 기록 | 해라체 | "종 아래를 지날 때 종이 아주 작게 흔들렸다." |
| **규칙 설명**: 스킬·상태·의도·유물 효과의 수치 부분 | 짧은 명사형. 문장 사이는 마침표, 마지막 문장 끝에는 찍지 않는다 | "{D:dmg} 참격 피해. 출혈 {bleed}" |

- 확인 창 말고는 앱처럼 상냥하게 말하지 않는다. 확인 창 밖에서 "~해요", "~하세요", "~할 수 있어요", "~예요"는 쓰지 않는다. 게임 화면은 금융 앱 안내문이 아니다. 합니다체는 어디서도 쓰지 않는다.
  - 알림과 짧은 안내는 명사형으로 끊는다: "저장 완료", "행동력 부족", "재사용 대기 2턴 남음".
  - 사용법 안내, 도움말, 용어집, 의도 설명은 해라체나 명사형: "누르면 설명. 한 번 더 누르거나 적을 누르면 사용. 길게 누르면 자세히"
- 한 창 안에서 말투를 섞지 않는다. 제목이 해요체 물음("~할까요?")인 확인 창은 본문도 해요체다. 제목이 명사인 행동 창(「X 흡수」, 「X 판매」)은 본문도 해라체나 명사형으로 둔다.
- 예외: 세계 안의 목소리는 세계 서술로 친다. 폰 알림을 흉내 낸 가짜 시스템 메시지(`sysmsg`, "화면 밝기를 낮추십시오."), 적 대사("살려 주세요…")는 공포 연출이라 합니다체·해요체를 그대로 쓴다.
- 맛글(분위기 문장)과 규칙 문장은 한 문장에 섞지 않고 나눈다.

## 2. 하지 않는 것 (AI 티)

- **긴 줄표(—)를 쓰지 않는다.**
  - 쉼표, 마침표, 쌍점(:), 괄호, 줄바꿈으로 바꾼다.
  - 예: "정수 자리 5/5 — 하나를 깨뜨려야 한다" → "정수 자리가 꽉 찼다(5/5). 하나를 깨뜨려야 한다."
  - 범위는 물결표(~)를 쓴다.
- **괄호 설명을 남발하지 않는다.** 한 문장에 괄호는 하나까지. 꼭 필요한 조건이 아니면 뺀다.
- **번역투를 쓰지 않는다.**
  - "~에 대해", "~를 통해", "~에 의해", "~을 가지고 있다", "~하는 것이 가능하다", "~되어진다"
  - 이런 표현은 바로 쓰는 말로 바꾼다.
- **같은 꼴을 되풀이하지 않는다.**
  - 같은 어미가 세 문장 넘게 이어지지 않게 한다(~한다. ~한다. ~한다.).
  - "그것은 ~였다"를 반복하지 않는다. "A, B, 그리고 C" 삼단 나열을 남발하지 않는다.
- **덮어씌우는 말을 쓰지 않는다.**
  - '무언가', '어딘가', '이상하게', '마치 ~처럼'은 한 글에 한 번까지.
  - 대신 구체적인 감각을 쓴다: 소리, 냄새, 온도, 색.
- **설명을 늘어놓지 않는다.**
  - 규칙 문장은 필요한 정보만 쓴다.
  - "~합니다. 이는 ~이기 때문입니다" 같은 이유 설명은 도움말에서만.
- **시점은 하나로.** 이벤트·맛글 서술은 2인칭이다. 대명사가 꼭 필요하면 '당신'을 쓰고 1인칭('나', '내')으로 바꾸지 않는다. 주어를 빼도 뜻이 통하면 뺀다. 규칙 설명은 '내 턴', '내 기술'처럼 쓴다.
- **과장하지 않는다.** '압도적인', '강력한', '엄청난' 같은 말 대신 숫자나 사실을 쓴다.
- **연결어미 뒤에 쉼표를 찍지 않는다.** 예: "~하고," "~지만,"

## 3. 용어는 하나로

| 쓰는 말 | 쓰지 않는 말 |
|---|---|
| 내 턴 / 적의 차례 | 플레이어 턴, 적 턴(혼용) |
| 피해 | 데미지, 대미지 |
| 방어도 | 쉴드, 방어력(방어도와 혼용) |
| 정신력 | 멘탈, 정신 |
| 행동력 | AP, 기력 |
| 재사용 대기 n턴 | 쿨다운, 쿨 |
| 버팀 · 붕괴 | 그로기, 스턴(붕괴의 뜻으로) |
| 흡수 / 병에 담기 / 깨뜨리기 (정수) | 획득, 장착(정수에) |
| 새기기 (각인) | 장착(각인에) |
| 수호자 / 계층군주 / 정예 | 보스(본문에서), 엘리트 |

- 숫자 서식: 스킬 피해는 지금처럼 숫자를 앞에 쓴다: `{D:dmg} 참격 피해`, `{B:blk}` 방어도 (전체가 이 꼴로 일관돼 있다). 그 밖은 `피해 7`, `방어도 +5`, `3턴`, `전투당 1회`, `최대 체력의 30%`.
- 보조 표기: 지도 알림은 `(지도에 표시)`, 정신 붕괴는 `정신이 무너졌다. (편집증)`처럼 괄호로 붙인다.
- 조건은 "~면"으로 쓴다: "출혈이 있으면 피해 +3".

## 4. 예

**규칙 설명**
- 전: "메스 끝으로 절개선 2개를 긋는다 — 「생체 해부」가 절개선마다 5 피해를 더 준다. 체력을 회복하면 아문다"
- 후: "절개선 2개를 긋는다. 「생체 해부」의 피해가 절개선마다 +5. 체력을 회복하면 아문다"

**시스템 UI**
- 확인 창은 해요체 그대로: "모든 기록을 초기화할까요?" / "도감, 해금한 캐릭터, 여정 횟수가 처음으로 돌아가요."
- 전: "스킬을 누르면 설명이 보여요. 한 번 더 누르거나 적을 누르면 사용해요."
- 후: "누르면 설명. 한 번 더 누르거나 적을 누르면 사용"
- 전: "골드가 부족해요" → 후: "골드 부족"

**세계 서술**
- 전: "진주를 뽑자 성상의 빈 눈구멍에서 검은 물이 흘렀다. 무언가를 알아버렸다."
- 후: "진주를 뽑자 성상의 빈 눈구멍에서 검은 물이 흘러내렸다. 짠물 맛이 혀끝에 남았다."

## 5. 바꾸면 안 되는 것

- id, 키, 코드, `vals`
- 설명 속 `{키}`·`{D:키}`·`{B:키}` 자리표시자. 테스트가 `desc`의 `{키}`가 `vals`에 있는지 검사한다.
- 숫자와 규칙의 뜻. 문장을 고쳐도 효과는 그대로여야 한다.
- 고유 이름(적·정수·유물·장비·스킬 이름). 이름은 그대로 두고 설명만 고친다. 명백한 번역투 이름만 예외.
- 실제 세계 토큰: `{time}`, `{hour}`, `{deaths}`, `{runs}`, `{wins}`, `{best}`, `{origin}`.
