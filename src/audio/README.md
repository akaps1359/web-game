# 오디오 모듈 (`src/audio`)

심연행의 음악과 효과음은 전부 코드로 합성한다(샘플 없음). Tone.js가 컨텍스트, 스케줄링(`Clock`), 버스(Gain/BiquadFilter/Panner), 공용 리버브(Convolver), 에코(PingPongDelay), 마스터 컴프레서·리미터를 맡는다. 실제 발음은 Tone 컨텍스트로 만든 네이티브 오실레이터·노이즈 버퍼와 AudioParam 오토메이션으로 한다.

이렇게 나눈 이유는 아이폰 CPU다. 오프라인 렌더로 측정해 보니 Tone의 `Synth`/`Filter`/`LFO`는 주파수·디튠이 Signal로 연결돼 있어 샘플마다 계산이 돌았고, 같은 소리를 네이티브 노드로 만들 때보다 4~8배 무거웠다. 지금은 보스 곡(리버브·정신력 효과 포함)이 데스크톱 크롬 기준 32kHz에서 코어 하나의 8~10% 정도이고(정신력 최저·강도 최대에서 15~19%), 앰비언트 곡은 5~8%다.

보스(수호자)·정예·영주 곡은 구간 구조를 가진 긴 곡이다(아래 '보스곡' 참고). 구간마다 레이어를 새로 만들고 끝나면 정리해서(쌓지 않고 갈아 끼움) CPU는 예전 한 루프짜리 보스 곡과 같은 수준이다.

## 빠른 사용법

```ts
import { audio } from './audio';

// 첫 터치 핸들러 안에서 (iOS는 반드시 제스처 안에서 동기 호출)
startButton.onclick = () => {
  audio.unlock();          // 여러 번 불러도 안전. 매 터치마다 불러도 됨
  audio.play('title');     // unlock 전에 불러도 기억했다가 재생
};

audio.play('explore', { act: 2 });   // 약 2초 크로스페이드. 같은 무드+막이면 무시
audio.play('boss', { act: 3, seed: 'a3-boss-king' }); // 씨앗(조우 id) = 수호자마다 다른 곡. 같은 무드+막+씨앗이면 무시
audio.setSanity(player.sanity);      // 0..100
audio.setIntensity(0.8);             // 0..1 (보스 2페이즈, 체력 위급 등)
audio.sfx('slash', { pitch: 1.05, volume: 0.9 });
audio.applySettings({ music: 0.5 }); // localStorage 'abyss.audio'에 저장
audio.registerTrack('haven', '/music/haven.m4a', { act: 4, volume: 0.9 }); // 선택: 실제 음원으로 교체
audio.registerTrack('boss', '/music/boss.mp3', { theme: true, end: 36.8 }); // 교체 대신 생성 곡 사이에 '테마'로 섞기
```

- `act`를 생략하면 마지막으로 쓴 막을 그대로 쓴다(처음엔 1). 5는 최종장(꿈꾸는 우주 — 별의 태아)이다.
- unlock 전에 부른 `sfx`는 무시한다. 무드와 정신력/강도 값은 기억했다가 unlock 직후에 적용한다.
- `unlock()`의 Promise는 컨텍스트가 running이 되면 resolve된다. 3초 안에 안 되면 그냥 resolve하고(게임이 await에서 멈추지 않도록), 다음 터치 때 다시 시도한다.

| `moods/form.ts` | 곡 형식 지휘자: 구간 진행, 강도에 따른 흐름(절정 앞당기기), 라이저·임팩트, 구간 노드 교체 |
| `moods/theme.ts` | 씨앗으로 만드는 8마디 주제와 변주(조각·확대·전위·역행·반복진행·당김), 선율 악기 12종, 아르페지오 |
| `moods/suite.ts` | boss, elite, lord — 막별 구간 레시피(드럼·오스티나토·화성 진행·선율 악기·질감), 수호자별 정체성 |
| `moods/stingers.ts` | victory, defeat |

## 막별 팔레트

| 막 | 으뜸음 / 음계 | 성격 |
|---|---|---|
| 1 항구 지하 | D / 자연단음계 | 우울하지만 현실적. 바다, 물방울, 피아노, 안개 경적 |
| 2 수도원 | B / 프리지안 | 성가와 의식. 포먼트 합창, 종, 오르간 드론 |
| 3 얼어붙은 고대 도시 | E / 도리안 | 광대하고 차갑고 외롭다. 산맥을 넘는 바람의 휘파람, 얼음 결정 같은 종, 얼음 밑의 낮은 드론, 먼 피리(테켈리-리) |
| 4 별들의 궁정 | C / 로크리안 + 미분음 | 광대하고 낯섦. 반음 군집 드론, 저주받은 피리, 7/8 |
| 5 꿈꾸는 우주 | A / 리디안 (#iv 감화음) | 광대함과 경이, 그 아래의 불안. 열린 5도 드론, 태아의 느린 심장박동, 낮은 합창, 별빛 |

## 무드

| 무드 | 설계 |
|---|---|
| `title` | D단조 고정 테마(8마디). 전자피아노 → 첼레스타 → 쉼으로 바퀴마다 변주. 드론, 바다, 바람, 먼 종, 8마디마다 낮은 호른 |
| `explore` | 막마다 완전히 다르다. 1: 파도·물방울·드론·느린 피아노·무적 / 2: 오르간 드론·합창(모음이 바뀜)·종·홀로 부르는 성가 / 3: 높은 바람의 휘파람과 낮은 눈보라·낮은 사인 드론·얼음 결정 종 선율·차가운 패드·아주 가끔 먼 피리 / 4: 반음 군집·피리·먼 북(5+7 박자)·별빛 / 5: 열린 5도 드론·심장박동·낮은 합창·별빛·종 |
| `combat` | 막별 드럼 패턴(타이코·톰·손바닥·쉐이커·쇠사슬), 화음 베이스 따라가는 오스티나토, 긴장 패드, 8마디마다 라이저. 1막 조율 안 된 피아노, 2막 합창+종, 3막 얼음 결정 아르페지오+눈보라+낮은 드론, 4막 7/8+피리, 5막 하프타임+낮은 합창+별빛 |
| `elite` | 보스곡과 같은 구간 구조의 짧은 판(도입 4 → A 8 → B 8 → 절정 8 → A' 8 → …). combat보다 6% 빠르고 반음 군집 금관 스탭. 주제 선율은 조금 작게 |
| `boss` | 수호자 곡. 구간 구조(아래 '보스곡'), 12% 빠름(수호자별 ±4%), 강도에 따라 템포 +10%·절정 앞당김. 1~4층은 38초 음원을, 5층은 88초 합창을 바퀴 사이에 '테마'로 끼운다 |
| `lord` | 숨겨진 층의 영주. 같은 구간 구조, 막과 무관하게 7/8. 오스티나토와 주제 선율의 음마다 고정된 미분음(±45 cents), 곡 내내 가라앉는 반음 군집 드론, 군집 합창, 스웰 |
| `rift` | 5/4, 온음음계, 화음이 떠돌고 2마디마다 템포가 ±14% 일렁인다. 늘어진 테이프처럼 휘는 북, 유리 아르페지오, 별빛 맥놀이 |
| `event` | 낮은 드론과 옅은 패드 위로 2~4마디마다 '질문 동기'(삼전음·장7도로 끝나는 3~4음)를 첼레스타로. 막별 질감(바다/허밍/바람과 별빛/피리/심장) |
| `merchant` | 조율이 어긋난 오르골 왈츠(3/4). 막마다 음계가 바뀌고(화성단음계→프리지안 도미넌트→온음→로크리안→이중화성), 12~22마디마다 태엽이 풀려 느려지고 음이 처졌다가 감는 소리와 함께 돌아온다 |
| `camp` | 모닥불(웅웅거림 + 탁탁 튀는 소리 + 가끔 큰 불똥), 따뜻한 삼각파 패드(가끔 b2 불안), 기타 같은 뜯는 음. 멀리서 들리는 불안의 기척(막별: 무적/종/눈보라/피리/심장) |
| `haven` | 층 사이 항구 마을. 6/8 하프 아르페지오, 파도, 높은 부표 종, 옅은 현, 느린 피아노. 막이 오를수록 느려지고 어두워진다(2막 허밍, 3막 별빛과 바람, 4막 군집 드론과 피리, 5막 드론과 심장박동) |
| `victory` | 약 7초. 단조 화음 위 팀파니 롤 → 장조로 풀리는 금관(피카르디 3화음) + 종 아르페지오 + 서브 붐 → 침묵 |
| `defeat` | 약 9초. 서브 붐과 낮은 반음 군집이 2.5반음 미끄러져 가라앉고, 세 번의 느려지는 심장박동, 들숨 같은 역스웰 뒤 뚝 끊긴다 |
| `silence` | 모든 음악 페이드아웃(2.5초). 정신력 이벤트도 멈춘다 |

모든 무드는 무작위로 생성된다. 선율은 음계 위를 걷다가 강박에서 화음음으로 끌리고, 프레이즈와 쉼을 번갈아 둔다. 드럼은 변형 패턴과 필인, 확률 음을 섞는다. 그래서 반복 루프처럼 들리지 않는다.

## 보스곡 (구간 구조, `moods/form.ts` · `theme.ts` · `suite.ts`)

수호자전(3~6분)에서 같은 대목이 똑같이 반복되지 않도록, 한 곡을 구간으로 나눠 구간마다 악기·드럼 패턴·화성 진행·선율 변주를 바꾼다.

| 구간 | 내용 |
|---|---|
| 도입 (8마디) | 바탕 드론 + 막 질감 + 큰북·톰만. 주제의 첫 두 마디를 두 배로 늘여 어두운 악기로(호른/합창/얼음 종/피리). 마지막 마디 라이저 → A 첫 박 임팩트 |
| A (16) | 막 킷 + 보스 패턴, 오스티나토, 금관 스탭. 8마디 주제 두 번 — 두 번째는 다른 악기가 한 옥타브 위에서 겹침. 화성 진행은 수호자마다 고정(주제를 알아듣게) |
| B (16) | 다른 그루브(하프타임·톰·행진), 다른 오스티나토, 다른 진행. 주제의 동기를 두 악기가 주고받는다(화음을 따라 반복진행, 대답은 전위) + 아르페지오 |
| A′ (8~16) | 주제 변주(전위/역행/반복진행/당김/확대 중 하나) + 원래 주제, 다른 드럼 변형 |
| 숨 고르기 (8) | 드럼 대신 2마디마다 낮은 북. 드론·패드·막 질감, 주제 앞 4마디를 두 배로 늘여 부드러운 악기로. 템포 -4%. 두 마디 라이저로 절정에 |
| 절정 (16) | 촘촘한 킷(16분 쉐이커·필인), 옥타브 겹친 오스티나토, 매 마디 스탭, 주제를 센 악기(금관/합창)로 두 번(두 번째는 다른 악기가 옥타브 위). 템포 +4%, 두 번째 절정부터 한두 음 조옮김 |
| 마무리 (4) | 바퀴 끝에 음원 테마로 넘길 때만: 임팩트 + 긴 화음 |
| 재진입 (4) | 음원 테마 뒤 다시 들어올 때: 도입처럼 얇게 시작 |

- **바퀴**: 1바퀴 = 도입 → A → B → A′ → 숨 고르기 → 절정 (1~4층 약 2분 10초~2분 40초). 다음 바퀴는 순서가 바뀐다(A′·B·숨 고르기·절정 / B·A·숨 고르기·절정·A′ …). 같은 역할이 연달아 오지 않게 자리를 바꾼다. 5층은 합창과 번갈아 돌도록 한 바퀴를 짧게(A 16 → B 8 → 숨 고르기 8 → 절정 16).
- **수호자별 변주**: `seed`(조우 id)로 8마디 주제(동기 리듬 9종·윤곽 7종·반복진행 폭·반음 비틀기), 구간별 선율 악기 조합(막마다 4종 중에서), A·도입·절정의 화성 진행, 아르페지오 모양, 템포(±4%), 절정 조옮김 폭(+1/+2)이 정해진다. 같은 수호자는 늘 같은 주제다. 연주 중의 우연(드럼 패턴 고르기, 확률 음, 휴먼라이즈)은 그대로 무작위.
- **강도 흐름**: 구간 시작 때보다 강도가 0.28 이상 오르면(수호자 체력 절반, 위기) 가까운 4마디 경계에서 끊고 절정으로 간다(앞서 계획된 절정은 B로 바뀜). 강도 0.7 이상이면 숨 고르기를 건너뛰거나 4마디로 줄인다. 구간 안에서는 기존처럼 쉐이커·옥타브 겹침·필터·템포가 강도를 따른다.
- **막별 악기**: 1층 금관·조율 안 된 피아노·하프·종 + 바다·무적·물방울 / 2층 합창·종·금관·오르간 + 오르간 드론 / 3층 유리·피리·얼음 종·금관 + 눈보라·유리 아르페지오 / 4층 피리(미분음)·금관·종·합창 + 반음 군집·먼 북 / 5층 합창·금관·첼레스타·유리 + 열린 5도·태아의 심장박동·별빛.
- **음원 테마(메들리)**: `registerTrack(mood, url, { theme: true })`로 등록한 음원은 생성 곡을 대체하지 않고, 한 바퀴가 끝날 때(절정 뒤) 마무리 임팩트와 함께 한 번 튼다. 테마가 끝나기 2.6초 전 생성 곡이 재진입 구간부터 다시 들어오고 바퀴 번호를 이어 센다. 생성 곡은 테마 동안 완전히 멈추고 정리된다(겹치는 건 넘어가는 2~3초뿐). 음원이 아직 디코딩 전이면 그 바퀴는 넘기지 않는다. `first: true`면 테마부터(5층 합창. 아직 디코딩 전이면 생성 곡 도입으로 시작했다가 준비되는 대로(12초 안) 크로스페이드), `end`는 루프용으로 붙은 꼬리(다시 시작하는 박) 앞에서 자르는 지점. 음원은 생성 곡보다 2~2.5dB 작게 마스터링돼 있어 `volume` 1.3/1.2로 맞췄다.
- **노드 정리**: 구간 레이어는 `Runtime.fork()`가 만든 하위 런타임(자기 Bag + 출력 게인)에 만든다. 구간이 끝나면 더는 진행하지 않고, 남은 소리를 1.2~2.5초 페이드한 뒤 하위 런타임째 dispose한다. 바탕 드론과 전환 효과만 곡 내내 산다.
- **측정(오프라인 렌더, 32kHz)**: 같은 조건에서 예전 한 루프 보스 곡과 번갈아 재면 곡 평균 CPU 보스 0.92~1.07배, 영주 1.03~1.11배, 정예 1.12~1.30배(그래도 보스보다 낮다). 정신력 20·강도 1의 최악 조건에서 절정 0.98~1.29배, A 0.92~1.21배, 숨 고르기 0.82~1.09배. 구간 음량(K-가중)은 도입·숨 고르기 ≈ -21, B ≈ -18.5, A ≈ -17.5, 절정 ≈ -16(`suite.ts`의 `ROLE_DB`). 6초 창 상호상관으로 본 '똑같은 반복'은 예전 38초 루프가 1.00, 생성 구간은 5분 반 동안 최대 0.47~0.79(상위 1% 0.30~0.38).

## 정신력(`setSanity`)

음악 버스 전체(`sanity.ts`)와 각 무드에 함께 작용한다. 모든 변화는 몇 초에 걸쳐 램프로 바뀐다.

| 정신력 | 효과 |
|---|---|
| 60 이상 | 효과 없음 |
| 60 → 30 | 테이프가 늘어지는 듯한 느린 피치 흔들림이 점점 커진다(최대 약 ±40 cents). 드론 디튠이 넓어지고 음마다 미세하게 음정이 어긋난다. 패드가 어두워진다 |
| 35 이하 | 화음에 단2도·삼전음·미분음 군집이 섞인다. 북과 오스티나토가 더 흔들리고, 스웰이 잦아진다 |
| 30 이하 | 음악이 먹먹해지고(최저 2.6kHz 로우패스) 거친 디지털 잡음(비트크러시)이 깔린다. 속삭임(무작위 패닝, 낮을수록 잦고 두 목소리가 겹침)과 역재생 같은 스웰이 나온다 |
| 20 이하 | 리듬 없는 곡에서 희미한 심장박동이 들리고, 정신력이 낮을수록 빨라진다(64→104 bpm) |

`title`·`victory`·`defeat`·`silence`에서는 속삭임·스웰·심장박동 같은 이벤트가 나오지 않는다(필터 효과는 그대로).

## 강도(`setIntensity`)

- 전투 계열: 템포 상승(일반 +6%, 보스 +10%), 쉐이커 등장, 오스티나토 옥타브 겹침과 사이 음, 필터 개방, 스탭·라이저 빈도 증가, 유리 아르페지오 밀도 증가.
- 앰비언트 계열: 드론·패드 필터가 열리고 바람이 날카로워진다. 심장박동 레이어가 빨라진다.

## 효과음(`sfx`)

`pitch`는 재생속도처럼 음높이와 길이를 함께 바꾼다(0.25~4, 보통 0.8~1.2). `volume`은 0..1 배율이다. 같은 효과음은 30ms 안에 다시 울리지 않는다.

| 이름 | 소리 |
|---|---|
| `click` / `select` / `error` | 짧은 틱 / 두 음 FM 핑 / 낮은 버저 두 번 |
| `slash` | 고역→중역으로 쓸려 내려가는 바람 소리 + 칼날 울림 |
| `pierce` | 짧은 고역 '칙' + 아래로 휘는 핑 + 둔탁음 |
| `gunshot` | 날카로운 크랙 + 저음 붐 + 어두워지는 꼬리 |
| `blunt` | 낮은 둔탁음 |
| `fire` | 휘몰아치는 노이즈 + 웅웅거림 + 불똥 |
| `arcane` | 맥놀이 FM 화음 + 위로 올라가는 반짝임 |
| `void` | 떨어지는 서브 + 역재생 같은 숨 + 비조화 FM 으르렁 |
| `block` | 금속 '쨍'(비조화 FM) + 둔탁음 |
| `heal` / `buff` / `debuff` | 올라가는 FM 아르페지오와 공기 / 열리는 톱니 + 핑 / 내려가는 맥놀이 FM |
| `break` | 유리 깨짐(고역 노이즈 + 비조화 FM) + 충격 |
| `enemyDeath` | 아래로 가라앉는 FM 으르렁 + 어두워지는 노이즈 |
| `playerHit` | 충격 + 짧은 노이즈 + 찌그러진 저음 |
| `sanityLoss` | 반음 어긋나 처지는 두 음 + 서브 + 짧은 속삭임 |
| `whisper` | 포먼트 속삭임 1~1.6초 |
| `levelUp` | G-D-G-B로 올라가 장3도로 끝나는 종 아르페지오 + 반짝임 + 낮은 붐 |
| `coin` / `essence` | 높은 금속 핑 두 번 / 위로 휘는 영혼 소리 |
| `footstep` | 젖은 돌바닥 발소리(가끔 물 튀김) |
| `door` | 삐걱(FM) → 쿵 |
| `portal` / `riftOpen` | 소용돌이 스윕 / 서브 스웰 + 반음 군집 + 금속 울림 |
| `reveal` | 올라가는 3음 첼레스타 |
| `bell` | 교회 종(허밍 음 포함) |
| `heartbeat` | 두근-두근 |
| `turnStart` | 부드러운 차임 |
| `charge` | 적이 힘을 모으는 상승음(라이저) |
| `victoryHit` | 결정타: 붐 + 크래시 + 금속 + 서브 |
| `breakdown` | 정신력 붕괴: 반음 군집 + 깊은 붐 + 닫히는 노이즈 + 속삭임 + 찌그러진 신음 |

## 성능과 iOS 메모

- **unlock**: `Tone.start()`와 1샘플 무음 버퍼 재생을 제스처 안에서 동기적으로 한다(구형 iOS 대응). 앱 전환이나 전화로 컨텍스트가 `interrupted`/`suspended`가 되면 다음 터치(`touchend`/`pointerup`/`click`/`keydown`) 때 재개한다.
- **숨김**: 페이지가 가려지면(`visibilitychange`, `pagehide`) 마스터를 60ms에 페이드한 뒤 AudioContext를 `suspend`하고, 다시 보이면 재개한다.
- **무음 스위치**: iOS에서 Web Audio는 기본적으로 무음 스위치를 따른다(다른 앱 음악과 섞임). 이 모듈은 오디오 세션 설정을 바꾸지 않는다.
- **스케줄링**: `lookAhead`를 0.2초로 늘려 PixiJS 렌더링 때문에 메인 스레드가 끊겨도 음악이 튀지 않게 했다. 효과음은 `immediate()+12ms`에 예약하므로 lookAhead와 상관없이 즉시 난다.
- **노드 수명**: 무드마다 만든 노드는 `Bag`에 모아 페이드아웃 직후 한꺼번에 dispose한다. 음표용 오실레이터와 노이즈 소스는 원래 1회용이라 음표마다 만들고, 끝나면 연결을 끊어 GC에 넘긴다. 동시 발음은 악기마다 상한이 있다. 효과음은 채널 10개(필터→음량→팬→센드)를 처음에 만들어 재사용한다. 너무 빠르게 무드를 바꿔도 페이드 중인 무드는 최대 2개만 유지한다. 테스트에서 무드를 40번 연속 전환한 뒤에도 Clock 리스너와 타이머 수가 처음과 같았다.
- **리버브**: Tone.Reverb의 비동기 렌더링 대신 4.2초짜리 어두운 IR(시간이 지날수록 고역이 먼저 사라짐)을 동기로 만들어 Convolver 하나를 음악·효과음이 공유한다.
- **음원 등록**: `registerTrack`으로 등록한 파일은 해당 무드에 처음 진입할 때 내려받는다. 받는 동안은 생성 음악이 나오다가 디코딩이 끝나면 2초에 걸쳐 크로스페이드한다(`theme: true`로 등록한 보스 음원은 대신 바퀴 끝에서 끼운다 — 위 '보스곡'). 디코딩된 버퍼는 메모리를 많이 먹어서(3분 스테레오 ≈ 60MB) 최근 3개만 캐시한다. iOS 호환을 위해 `.m4a`(AAC)나 `.mp3`를 권장한다. 정신력 효과는 음원에도 걸린다.

## 음량 조정

각 무드의 전체 음량은 `MoodSpec.gain`(dB)으로, 효과음은 `sfx.ts`의 `TRIM` 표로 맞춘다. 현재 값은 오프라인 렌더로 측정한 K-가중 음량을 기준으로 정했다(앰비언트 ≈ -21, 전투 ≈ -19, 보스·영주 ≈ -17.5, 효과음 피크는 UI -14 / 공격 -7~-9 / 타격 -2~-6 dBFS). 음악 페이더는 제곱 커브에 +3dB 보정이 붙고, 기본 설정은 음악 0.7, 효과음 0.85다.
